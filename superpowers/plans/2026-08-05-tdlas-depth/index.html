    TDLAS Deep-Dive Implementation Plan¶

    For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

    Goal: Deepen SPEKTRAN's TDLAS implementation across physics accuracy, computation performance, benchmark coverage, and sim-to-real validation — making it the most rigorous open-source TDLAS simulation engine available.

    Architecture: Nine tasks organized by priority (P0→P3). P0 unblocks downstream work (vectorized absorption, DL baseline scores). P1 adds the most impactful physics (HTP line shape) and benchmark breadth (multi-species). P2 deepens WMS, adds temperature regression, and completes the noise chain. P3 adds advanced physics and literature-based sim-to-real validation.

    Tech Stack: Python 3.10+, NumPy (broadcasting for vectorization), SciPy (wofz for HTP), PyTorch (DL baselines on CPU), pytest, existing SPEKTRAN infrastructure.

    Files: - Modify: src/spektran/physics/absorption.py:82-117 - Create: tests/test_vectorized_absorption.py

    The current absorption_coefficient has a Python for j in range(len(lines)) loop that computes one Voigt profile per line. With HITRAN production data (100-300 lines × 2000 frequency points), this is the main bottleneck.     def absorption_coefficient(nu_cm1, lines, mole_fraction, temperature_K, pressure_atm, q_ratio=None, wing_cutoff_cm1=0.0):
    if not 0.0 <= mole_fraction <= 1.0:
        raise ValueError(f"mole_fraction must be in [0, 1], got {mole_fraction}")
    q = (q_ratio or tips_q_ratio)(lines.molecule, temperature_K)
    strengths = line_strength_at_T(
        lines.sw_cm_per_molec, lines.nu0_cm1, lines.elower_cm1, temperature_K, q
    )
    n_absorber = number_density_cm3(pressure_atm, temperature_K) * mole_fraction

    nu0_shifted = lines.nu0_cm1 + lines.delta_air * pressure_atm  # (n_lines,)
    a_d = np.array([doppler_hwhm_cm1(nu0, temperature_K, lines.molar_mass_amu) for nu0 in nu0_shifted])
    g_l = np.array([
        lorentz_hwhm_cm1(pressure_atm, temperature_K, lines.gamma_air[j],
                         lines.gamma_self[j], mole_fraction, lines.n_air[j])
        for j in range(len(lines))
    ])

    # Vectorized Voigt: (n_lines, n_points) broadcasting
    alpha = _voigt_sum_vectorized(nu_cm1, nu0_shifted, a_d, g_l, strengths, wing_cutoff_cm1)
    return n_absorber * alpha

    Add _voigt_sum_vectorized that uses wofz with 2D complex arrays:

    def _voigt_sum_vectorized(nu_cm1, nu0, a_d, g_l, strengths, wing_cutoff_cm1=0.0):
    sigma = a_d / np.sqrt(2.0 * np.log(2.0))  # (n_lines,)
    # nu_cm1: (n_points,), nu0/sigma/g_l: (n_lines,) -> broadcast to (n_lines, n_points)
    delta = nu_cm1[np.newaxis, :] - nu0[:, np.newaxis]  # (n_lines, n_points)
    if wing_cutoff_cm1 > 0.0:
        mask = np.abs(delta) <= wing_cutoff_cm1
    z = (delta + 1j * g_l[:, np.newaxis]) / (sigma[:, np.newaxis] * np.sqrt(2.0))
    phi = np.real(wofz(z)) / (sigma[:, np.newaxis] * np.sqrt(2.0 * np.pi))  # (n_lines, n_points)
    if wing_cutoff_cm1 > 0.0:
        phi = np.where(mask, phi, 0.0)
    return np.sum(strengths[:, np.newaxis] * phi, axis=0)  # (n_points,)

    Task 3: Hartmann-Tran Profile (HTP) Line Shape (P1)¶

    Files: - Create: src/spektran/physics/lineshape_htp.py - Create: tests/reference_impl/ref_lineshape_htp.py - Create: tests/test_lineshape_htp.py - Modify: src/spektran/physics/hitran.py (extend LineList) - Modify: src/spektran/physics/absorption.py (integrate HTP option) - Modify: src/spektran/physics/__init__.py

    Implement the Hartmann-Tran Profile (HTP) — the HITRAN2016+ recommended line shape that accounts for speed-dependent broadening, speed-dependent shifting, Dicke narrowing, and their correlations. The implementation follows Ngo, Lisak, Tran & Hartmann, JQSRT 129 (2013) 89-100, Algorithm 1.

    • [ ] Step 1: Extend LineList with HTP parameters

    Add optional HTP fields to LineList in hitran.py:

    @dataclass
class LineList:
    # ... existing fields ...
    # HTP parameters (HITRAN2020 beyond-Voigt, optional)
    gamma_2: np.ndarray | None = None    # speed-dependent width [cm-1/atm]
    delta_2: np.ndarray | None = None    # speed-dependent shift [cm-1/atm]
    nu_vc: np.ndarray | None = None      # velocity-changing frequency [cm-1/atm]
    eta: np.ndarray | None = None        # correlation parameter [-]
    • [ ] Step 2: Write HTP line-shape function

    Create lineshape_htp.py implementing Algorithm 1 from Ngo et al. 2013:

    def htp_profile(
    nu_cm1: np.ndarray,
    nu0_cm1: float,
    doppler_hwhm: float,
    gamma_0: float,     # Lorentzian HWHM (pressure-broadened)
    delta_0: float,     # pressure shift
    gamma_2: float = 0.0,   # speed-dependent width
    delta_2: float = 0.0,   # speed-dependent shift
    nu_vc: float = 0.0,     # velocity-changing collision freq
    eta: float = 0.0,       # correlation parameter
) -> np.ndarray:
    """Hartmann-Tran Profile (area-normalized, units cm).

    Reduces to Voigt when gamma_2 = delta_2 = nu_vc = eta = 0.
    """

    The core algorithm: compute the speed-averaged complex probability function using two evaluations of wofz, combined via the HTP formula.

    • [ ] Step 3: Write independent reference implementation

    Create tests/reference_impl/ref_lineshape_htp.py using a completely different algorithm (direct numerical quadrature over the Maxwell-Boltzmann speed distribution, integrating speed-dependent Lorentzians).

    • [ ] Step 4: Write tests

    • Degenerate limit: HTP with gamma_2=delta_2=nu_vc=eta=0 must match Voigt

    • Area normalization: integral of HTP must equal 1
    • G3 cross-validation: main vs reference within 1e-6 relative

    • Known values from Table 1 of Ngo et al. 2013
